# Contributing

Thank you for helping. A few things to know first.

- **Licence.** The GreenLight Motion Engine is licensed under the [Apache License 2.0](LICENSE). Anything you
  contribute is licensed under the same terms ("inbound = outbound"); there is no separate agreement to sign.
- **Sign your commits.** Add a `Signed-off-by: Your Name <you@example.com>` line to each commit
  (`git commit -s`). It certifies the [Developer Certificate of Origin](https://developercertificate.org/): the
  contribution is yours to give, or you have the right to submit it under the project's licence.
- **Where the code comes from.** This repository is published from the GreenLight Dash source on every release.
  The engine is the same code GreenLight Dash's Video Editor renders with, so a change is checked against the
  app too before it lands. Accepted pull requests are applied there and come back in the next release.
- **Tests.** Describe how you checked your change: a project that shows it, a still before and after, the gate
  you ran. Engine changes need identical pictures for everything they don't mean to change.
- **Names.** Forks and derived products must use their own name (see [legal/TRADEMARKS.md](legal/TRADEMARKS.md)).

Questions: support@greenlightdash.pro.
